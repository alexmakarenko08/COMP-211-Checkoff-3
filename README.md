# COMP-211-Checkoff-3
For check-off 3, I explored stack buffer overflows, which are a memory safety vulnerability that happens when 
a program writes beyond the allocated boundaries of a local array, potentially corrupting nearby memory.
I looked more closely into how stack memory and stack frames work, as well as how out of bounds writes
occur in C, and the consequences of memory corruption including variable changes, incorrect program output,
and crashes. I also explored the differences between C and more high level languages such as Java with how
they handle array access. Finally, I examined ways to prevent these vulnerabilities through bounds checking,
input validation, and safer practices.
